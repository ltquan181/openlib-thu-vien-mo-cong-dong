# OpenLib — Nền tảng Thư viện Mở Cộng đồng

Hệ thống quản lý và chia sẻ sách, tài liệu học tập và tranh nghệ thuật cộng đồng phi lợi nhuận.

## 🚀 Công nghệ sử dụng
- **Frontend**: React (Vite), Tailwind CSS, Lucide Icons
- **Backend**: NodeJS, Express REST API
- **Database**: MySQL (Docker / Localhost)
- **Design Theme**: Xanh cỏ cây tự nhiên (Grass Green & Amber)

## 📦 Cài đặt & Khởi chạy dự án

### 1. Cài đặt thư viện
```bash
npm install
```

### 2. Chạy Backend Server
```bash
node server/index.js
# Backend chạy tại: http://localhost:5000/api
```

### 3. Chạy Frontend Web
```bash
npm run dev
# Website chạy tại: http://localhost:3000
```

## 🐱 Tính năng chính
- Khám phá kho sách cộng đồng & kho tranh trực quan
- Đọc sách online trực tiếp trên trình duyệt
- Chế độ đọc linh hoạt: Ban ngày, Đọc sách (Sepia dịu mắt), Ban đêm (Dark)
- Trao đổi sách ngang hàng (P2P), mượn trả tiện lợi
- Tìm kiếm tức thì và bộ lọc chuyên sâu
